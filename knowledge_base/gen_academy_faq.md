# Gen Academy FAQ Knowledge Base

This is the single approved knowledge source for the FAQ bot. Every entry below is a
generic, de-identified question-and-answer pair covering the recurring questions cohort
members ask. It contains no student names, no message excerpts, and no cohort-specific
data — only the general guidance that applies to any cohort.

The bot answers strictly from this document for course-mechanics questions. Career and
job-transition questions, and anything involving billing, promo codes, account access,
scores, or certificates, are routed to a human (TA/program staff) instead of being
answered from this document.

## Resources, Recordings & Access

Q: Where can I find this week's session recording?
A: Recordings are posted on the Maven course portal under that week's session page,
usually within a day of the live session. Open the week's page and look for the
session recording alongside the slides.

Q: Where can I find the slides or handout for a session?
A: Slides and handouts are posted on Maven under the same week's session page as the
recording.

Q: I can't find the solution kit for a project.
A: Solution kits are posted on Maven under that week's project page, typically after
the submission deadline for that project has passed.

Q: Will guest lectures be recorded?
A: Guest sessions are generally recorded and posted on Maven the same way as regular
sessions, though availability can occasionally depend on the guest speaker's
permission.

Q: A resource page or document looks empty or is missing content.
A: This is usually a temporary publishing gap. Check back after the related session
has concluded; if it is still empty after that, contact program staff so they can fix
the page.

Q: Where do I find tool credits or promo code information?
A: A consolidated list of course tool credits and how to redeem them is posted on
Maven. If a specific code is not working, that needs a human to check, since credit
providers change or expire codes independently of the course schedule.

## Logistics & Scheduling

Q: What time is today's session, and where do I get the join link?
A: Session times and join links are shared through the Maven calendar invite and the
cohort announcement channel ahead of each session.

Q: I don't have the calendar invite for an upcoming session.
A: Calendar invites go out through Maven and the cohort channel before each session.
If one is missing, check the Maven course calendar directly, or ask program staff to
resend it.

Q: Is there a different channel or cohort space for my start date?
A: Cohorts each have their own dedicated channel. Check the channel list in your
current space; if you don't see one for your cohort, ask program staff to confirm or
create it.

Q: Will office hours or a group chat session be recorded?
A: Recurring sessions such as office hours generally follow the same recording and
posting process as regular class sessions, published on Maven afterward.

## Project Submission Process

Q: How do I submit a project?
A: The typical flow is: push your project to a GitHub repository, record a short demo
video (a tool like Loom is common), and submit both links through that week's
submission form on Maven.

Q: Is there a naming convention for the GitHub repo I submit?
A: Check that week's project handout on Maven for any naming convention; if none is
specified there, a clear, descriptive repository name is sufficient.

Q: What is the deadline for this week's project?
A: Deadlines are listed in that week's project handout and on the Maven course
calendar. They are typically specified in Pacific Time, so double-check the time zone
stated in the handout.

Q: Do I need to keep building on the same project each week, or can I start a new use
case?
A: This varies by week and is specified in that week's project handout — some weeks
extend the previous project, others introduce a new use case. Check the current
week's handout for the exact requirement.

Q: Is it mandatory to complete every part of a project (for example, Part A and Part
B), or can I choose one?
A: Check that week's project handout — it will state which parts are required and
which are optional or a choice between alternatives.

Q: How do I record my screen for a project submission?
A: Any standard screen-recording tool (such as Loom, or your OS's built-in screen
recorder) is acceptable, as long as the resulting video is shared as a link you can
submit through the submission form.

## Technical & Course Mechanics

Q: What tool stack is used in this course?
A: The tool stack (editors, frameworks, model providers, etc.) is introduced
progressively in each week's session materials and handout on Maven.

Q: Do I need my own API key to connect to an LLM, or is one provided?
A: Guidance on API keys and provider access for each week's project is included in
that week's handout and session materials on Maven.

Q: Where can I find this week's project requirements or specs?
A: Each week's requirements/specs live in that week's project handout on Maven.

Q: Will there be documentation on deploying to a specific cloud platform (for example,
Vertex AI or another hyperscaler)?
A: Deployment guidance, when covered, is included in that week's session notes or
solution kit on Maven. If it isn't covered for the platform you're using, check with
program staff for pointers.

Q: Is LLM evaluation covered in this course?
A: Evaluation of LLM-powered applications (including RAG, agents, and tool-calling
systems) is covered as part of the course content; check the session notes for the
week it's introduced for specifics.

Q: Do I need a local install of a tool (for example, n8n), or can I use the hosted
web version?
A: Whether a local install is required is specified per project in that week's
handout — many tools also offer a hosted web option that can be used unless the
handout says otherwise.

## Certification Process

Q: What is the general process to receive the Gen Academy certificate?
A: Certification is based on completing the required weekly projects and the final
self-assessment. The exact requirements and timing are communicated by program staff
and posted on Maven.

Q: Is there a minimum score requirement to be certified?
A: Any minimum score or completion threshold for certification is set by program
staff and communicated through course announcements — check the certification
guidance posted on Maven for the current cohort's requirements.

Q: What other industry-recognized certifications are related to this course?
A: Related certifications, if any are highlighted for a given cohort, are announced
by program staff through course communications rather than fixed in this document.
